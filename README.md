# Bijoy to Unicode Converter

A small Windows app that converts Bijoy (ANSI) Bangla text into Unicode Bangla. It works fully offline and collects no data.

## Features

- Convert Bijoy (ANSI) text to Unicode Bangla
- Copy the result with one click
- Runs entirely on your PC, with no internet connection needed
- No analytics, ads, or tracking

## Download

Get the latest installer from the [Releases](../../releases) page.

1. Download `BijoyConverterSetup-1.0.0.exe`
2. Run it and follow the setup steps
3. Open **Bijoy to Unicode Converter** from the Start menu

**Requirements:** Windows 10 or Windows 11

## How to use

1. Paste your Bijoy text into the input box.
2. Select **Convert**.
3. Select **Copy** and paste the Unicode text wherever you need it.


## Privacy

The app does not collect, store, or send your text or personal information. Read the full [Privacy Policy](https://sites.google.com/view/bijoy-to-unicode-pv/).


## Known limitations

- Bijoy is a commercial font. This app converts characters only and does not include or distribute any Bijoy font files.
- Rare conjuncts may convert incorrectly. Please report them as issues with a sample.
